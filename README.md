# Preventive Vigilance Quiz

A timed online quiz on preventive vigilance for employees of AIIMS Bhopal, conducted by the institute's Vigilance Cell.

The quiz has 15 multiple-choice questions drawn from the Central Vigilance Commission's Vigilance Manual 2026. It covers the basics of preventive vigilance, cyber security and e-hygiene, procurement and the Integrity Pact, and conflict of interest.
